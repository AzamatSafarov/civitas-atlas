# Contributing

1. Open the project issue form or a pull request against `data/community-submissions.json`.
2. Include id, name, description, location, officialURL, sourceURLs, contributor and license (`CC-BY-4.0`).
3. Write your own short description, not a copied marketing page. By submitting you represent that you can license this original text under CC BY 4.0. Third-party media need a separate source, license and attribution; do not attach unlicensed images.
4. Preserve the difference between project statements and confirmed facts. A virtual or unknown location is valid. Do not guess population, revenue, founding dates, legal status or coordinates.
5. Run `python scripts/validate_submissions.py`.
6. Maintainer reviews accuracy, scope, duplication and rights. Passing CI is not editorial acceptance. Approved submissions are not automatically deployed; publication is a separate reviewed action.

Corrections may use regular issues. Security concerns, private data and rights disputes should be sent to akutagavasora777@gmail.com. No harassment, impersonation or promotional spam.
