## Что это

CIVITAS ATLAS собирает сведения о сетевых сообществах, проектах сетевых государств, экспериментальных городах, специальных экономических зонах и микронациях. Поиск, карточки проектов, глобус и карта помогают находить и сопоставлять инициативы по их устройству, членству, общим ресурсам, географии и отношениям с государствами.

Это разные организационные формы. Включение в атлас не означает признанной государственности.

Автор и куратор — **Азамат Сафаров**. Его работа включает интеграцию источников, проверку дублей, классификацию, сохранение происхождения сведений, проверку координат и разработку интерфейса. Авторство исходных текстов, фотографий и символики остаётся за их создателями.

## Объём и достоверность

Опубликованный на сайте исследовательский набор содержит **166 записей**: **126** в основном каталоге, **4** в архиве и **36** с неподтверждённым статусом.

Архивная запись не обязательно означает исчезновение сообщества; неподтверждённый статус не означает закрытие. Отметки на карте могут обозначать приблизительные районы или исторические площадки, а не действующие штаб-квартиры и границы.

> [!IMPORTANT]
> Это выбранный исследовательский срез, не полный мировой реестр. Утверждения источников и текущая деятельность не проверены независимо для всех записей. MIT относится к оригинальному коду, а не ко всей базе и сторонним изображениям.

В репозитории сохраняются отдельный прежний исследовательский снимок и индекс источников. Их состав отличается от отбора для действующего сайта: [объём данных](DATASET-SCOPE.md).

## Локальный запуск

Для просмотра проектов используйте [действующий сайт](https://polis-network-atlas.vercel.app). Локально можно запустить автономную страницу подачи предложений. Нужны Python 3 и Git:

```bash
git clone https://github.com/AzamatSafarov/civitas-atlas.git
cd civitas-atlas
python preview.py
```

Откройте **http://127.0.0.1:8850**. Пакеты Python и API-ключи не требуются. Это отдельная страница для участников, не полная копия атласа; не все производственные библиотеки и медиаресурсы включены в репозиторий.

Проверка новых предложений:

```bash
python scripts/validate_submissions.py
```
