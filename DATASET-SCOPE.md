# CIVITAS ATLAS dataset scope

166 records in combined-v3.json. This is the current network-project catalog, separate from the CHRONOTOPE Databank. No expanded commune/SEZ historical source layers are merged into this dataset.

All166 identities and existing source/status fields are preserved. This count is NOT a claim that all166 currently operate: historical, forming and uncertain projects remain represented. Current operating status requires source-by-source verification. Existing geographical unknowns remain null; no arbitrary country-centre markers.

The full research Databank is a separate private repository: https://github.com/AzamatSafarov/civitas-chronotope-databank . Its public interface is https://civitas-chronotope.vercel.app . Source data and third-party image rights are separate from code licensing.
