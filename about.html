About the project

CIVITAS ATLAS is an independent research project by Azamat Safarov about network communities, experimental cities and new forms of governance. Its purpose is to collect and compare information on project geography, membership, institutions and history while retaining the sources.

The database is available for browsing. The public repository contains our code, a source index and a mechanism for accepting original contributions. The current database as a whole is not declared to be freely licensed: rights to third-party descriptions, photographs and source collections have not been established.

Add a project or correction

Submit through GitHub Issues or submit a Pull Request. Provide the official website, your own description, the location and sources. Accepted original contributions are published under CC BY 4.0 with attribution. Do not submit images belonging to others without permission, private data or promotional spam.

The editor checks topical relevance, duplicates, sources and rights. Acceptance of a submission does not confirm the statehood of a project. Changes do not appear on the site automatically; review and publication are currently manual.

Reliability and limitations

The research dataset contains 166 project records: 126 in the main catalog, 4 in the archive and 36 with unconfirmed status. This is a selected research snapshot, not a complete list of network states worldwide. Not all dates, statistics and legal claims have been independently verified. The atlas does not provide legal, investment or immigration advice.

Privacy

Search runs in the browser. There is no registration, no analytics cookies set by this application and no advertising tracking. Vercel may process IP addresses and request logs. The flat map requests CARTO tiles. GitHub submissions and correspondence in Issues are public; email requests contain sender data and are used to process the request. A formal retention period and the applicable law require separate determination.
