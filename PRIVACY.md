# Privacy

The current atlas has no account registration, first-party analytics, ad tracking or submission backend. Search is processed in the browser. Vercel may process IP and request metadata under its policies. The optional flat map requests CARTO tiles; destination websites receive requests when external links are followed. The globe images in the deployed snapshot are hosted with the site.

GitHub submissions, account names, attachments and comments can be public. Do not submit private contact data or personal identifiers. Email requests contain sender details and correspondence used to handle the request. Actual hosting retention periods, applicable jurisdiction and a formal retention/deletion schedule have not yet been established; do not interpret this notice as a verified GDPR or other regulatory compliance certification.

For correction/removal requests use email. Removal from our site or repository cannot guarantee deletion from forks, caches, archives or third-party platform records. GitHub and Vercel have separate policies.
